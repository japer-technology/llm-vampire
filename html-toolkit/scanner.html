CORS playbook

About “detected”. A node like http://192.168.1.225:1234 can answer the browser but block readable responses. That means the scanner can prove there is an HTTP responder, but cannot safely read models until the owner enables CORS.
  • On the LM Studio host, enable Serve on Local Network and Enable CORS.
  • For headless runs, use the local equivalent of lms server start --cors --port 1234.
  • Pair CORS with auth on untrusted networks; this page only scans targets you configure.
