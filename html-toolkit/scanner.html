How detection works. The browser can only read an LM Studio response when that node has Enable CORS switched on. Such nodes show as online with full model details. Hosts that answer but block cross-origin reads are reported as detected (CORS off) — likely LM Studio, but you must enable CORS on that machine to interrogate it. Browsers cannot perform raw TCP/port scans, so closed ports and CORS-blocked nodes can look similar; treat detected as a strong hint, not a guarantee.
